# SheoMart - Product Requirements Document (PRD)

## Project Overview

**Project Name:** SheoMart

**Version:** v1.0

**Platform:**
- Mobile Application (React Native)
- Admin Dashboard (Next.js)
- Backend API (Node.js + Express)

---

# Vision

To digitally empower local grocery stores by providing a secure, scalable, and user-friendly marketplace where customers can discover nearby stores, browse products, place orders, and manage purchases while enabling store owners to efficiently manage inventory and business operations.

---

# Mission

- Digitize local grocery stores.
- Simplify grocery ordering.
- Provide secure digital commerce.
- Support trusted customer credit purchases.
- Build a scalable multi-tenant platform.

---

# Initial Launch Region

District: Sheopur (Madhya Pradesh)

Future versions will support multiple districts and cities without requiring architectural changes.
