# Purpose

This document defines the reusable UI components and design standards used throughout SheoMart.

Every screen should be built using these components whenever possible to ensure consistency, maintainability, and scalability.

# Accessibility

- Touch targets minimum 48x48dp
- Consistent navigation
- Readable typography
- Screen reader friendly labels
- Accessible color contrast

---

# Reusability Rules

- Never duplicate UI components.
- Create reusable components before copying layouts.
- Keep components small and composable.
- Separate presentation from business logic.
- Use shared design tokens for colors, spacing, and typography.

---

# Design Goals

The SheoMart design system should provide:

- Consistency
- Maintainability
- Scalability
- Accessibility
- High performance
- Professional user experience
- Easy future expansion
