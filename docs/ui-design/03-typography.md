# Accessibility Guidelines

- Minimum body font size should be 14.
- Avoid long paragraphs.
- Use sufficient line height.
- Maintain readable spacing.
- Support dynamic font scaling where possible.
- Do not rely solely on font weight to convey importance.

---

# Typography Principles

- Prioritize readability.
- Use consistent sizing.
- Maintain clear hierarchy.
- Limit font weights to those defined in this guide.
- Use bold text only where emphasis is required.
- Keep UI clean and uncluttered.
- Ensure consistent typography across all platforms.
