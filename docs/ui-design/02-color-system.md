The color system aims to create a clean, modern, trustworthy, and grocery-focused visual identity.

# Design Principles

- Use Primary Green for primary actions.
- Use Orange only for promotions.
- Never use Error Red for decorative elements.
- Maintain sufficient color contrast.
- Use semantic colors consistently.
- Avoid excessive color usage on a single screen.

---

# Accessibility

The application shall:

- Maintain WCAG AA contrast ratios where practical.
- Avoid using color alone to communicate information.
- Pair status colors with icons or labels.
- Ensure readability in bright outdoor conditions.
