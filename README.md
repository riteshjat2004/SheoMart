# 🛒 SheoMart

A full-stack multi-vendor grocery marketplace built with the MERN ecosystem, designed to connect local grocery stores with customers through a secure, scalable, and modern shopping experience.

> **Status:** 🚧 Active Development

---

## ✨ Overview

SheoMart enables customers to discover nearby grocery stores, browse products, place orders, and track purchases, while providing dedicated dashboards for Store Owners and Platform Administrators to manage the marketplace.

The project is being developed with a strong focus on:

- Clean Architecture
- Security
- Scalability
- Role-Based Access Control
- Modern UI/UX
- Production-Ready Development Practices

## 📁 Project Structure

```text
sheomart/
├── sheomart-frontend/
└── sheomart-backend/
```

Both applications follow a modular architecture with separation of concerns for scalability and maintainability.

---

## 🚀 Getting Started

```bash
# Clone Repository
git clone <repository-url>

# Frontend
cd sheomart-frontend
npm install
npm run dev

# Backend
cd sheomart-backend
npm install
npm run dev
```

Create `.env` files using the provided `.env.example`.
